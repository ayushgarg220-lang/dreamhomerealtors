DREAM HOME REALTORS – QUICK PROJECT IMAGE UPDATE

You do NOT need to edit HTML for normal project image changes.

1. Extract this ZIP on your computer.
2. Open the assets folder.
3. Open the project folder you want to update.
4. Replace the image file with your new image, keeping EXACTLY the same filename.
5. Keep the image in the same folder.
6. ZIP the whole website folder again OR upload the website folder to Netlify.
